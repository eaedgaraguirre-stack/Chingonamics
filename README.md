# Chingonamics

Mexican Meme Machine

## Branding assets

- `chingonamics-primary-dark.svg` is the default logo asset and the source of the compatibility `logo.svg` file.
- `chingonamics-primary-light.svg` should be used when the logo sits on dark backgrounds.
- `chingonamics-wordmark-dark.svg` and `chingonamics-wordmark-light.svg` are for wordmark overlays on photos or video, with the dark or light variant chosen for contrast.
- `chingonamics-favicon.svg` is the favicon/app icon asset for site metadata and browser tabs.
- The wordmark SVGs are stored as outlined paths so they do not depend on Helvetica/Arial being installed on the viewer device.
